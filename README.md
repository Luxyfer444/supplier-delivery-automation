Supplier-delivery-automation

Automated supplier delivery notification system built with Google Apps Script.
________________________________________________________________________________________________________________________________

OVERVIEW

Supplier Delivery Automation is a Google Apps Script application that automates supplier delivery notifications directly from Google Sheets.

Instead of manually filtering suppliers, preparing reports, creating Excel files and sending emails individually, the application performs the complete workflow automatically.

FEATURES

- HTML email generation
- Excel attachment generation
- Hybrid sending mode
- Email preview
- Simulation mode
- Supplier grouping
- Delivery tracking
- Custom email templates
- Signature management

ARCHITECTURE

(UI) -> Business Logic -> Google Sheets -> Gmail -> Drive
