# System Architecture

## 1. Purpose

Supplier Delivery Automation is a Google Apps Script application
designed to automate supplier delivery notifications using
data stored in Google Sheets.

The application groups pending purchase order actions by supplier,
generates email content, optionally creates Excel attachments,
sends notifications through Gmail, and updates delivery statuses.

## 2. Main Components

### User Interface

The application provides a custom sidebar inside Google Sheets.

Users can configure email templates, manage signatures,
select sending modes, simulate deliveries, and execute the
notification workflow.

### Data Sources

The application uses Google Sheets to store and process data.

- `OPOR`: Source data used to populate the operational index.
- `INDEX`: Working dataset containing purchase order actions
  and delivery statuses.
- `Mail Master`: Supplier contact information and email recipients.
- `SIMULACRO_REPORTE`: Output sheet generated by the simulation process.

These names describe the current implementation and should
be verified against the original spreadsheet.

### Business Logic

The backend processes the data, groups pending actions by supplier,
retrieves supplier contact information, and determines how each
notification should be delivered.

### Email Generation

The application supports HTML email tables and Excel attachments.

In hybrid mode, the delivery format depends on the number
of pending rows associated with each supplier.

### Delivery and Status Tracking

The application sends emails through Google Apps Script's
Gmail service and updates the corresponding delivery statuses
in the `INDEX` sheet.

## 3. High-Level Data Flow

1. Source data is imported into the operational index.
2. Pending actions are identified.
3. Actions are grouped by supplier.
4. Supplier contact information is retrieved.
5. The notification format is selected.
6. Email content and optional attachments are generated.
7. Emails are sent.
8. Delivery statuses are updated.

## 4. External Services

- Google Sheets: Data storage and spreadsheet interface.
- Google Apps Script: Application runtime and automation logic.
- Gmail: Email delivery.
- Google Drive: Temporary spreadsheet files used to generate
  Excel attachments.

## 5. Current Architecture

The application currently combines its user interface,
data processing, email generation, and delivery logic
within a Google Apps Script project.

A future refactoring phase may separate these responsibilities
to improve readability, testing, and maintainability.
